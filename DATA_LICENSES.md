## The data release

The archive holds three kinds of content.

**Items.** The 12,987 collected items (`rq12_transitions_s*/transitions.jsonl`) are text produced by the ALFWorld environment (ALFWorld on TextWorld, from ALFRED scenes, all MIT) while an agent played it, together with labels computed by this project. The agent's actions in each history were generated by Qwen3-8B. The game files were obtained through Word2World's download script, which fetches them from the dataset above. Word2World's only change that shows in the items is verb wording in the action set (`move` for `put`, and a `help` action). One field of each item, `hidden_state`, is different: it is Word2World's own text, a starting-layout description copied verbatim from that dataset's `init_contexts/alfworld/wm_instruct_*.json`. Because that dataset declares no licence, the field is removed from the release. The RQ2 analysis never reads it, and the release keeps its SHA-256 (`hidden_state_sha256`) so that anyone with the upstream data can check it. The MIT licences require their notices to travel with the material, so the archive carries copies under `rq2_release/licenses/`.

**Scores.** `rq2_score/shard_*/scoring.jsonl` holds numbers this project computed from two models' log-probabilities: Qwen3-8B and Llama-3.1-8B-Instruct.

**Written predictions.** `rq2_score/shard_*/generations.jsonl` holds the two models' short generated predictions, one sentence or so per item and condition. The analysis reads them for one provisional secondary measure.
